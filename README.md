# 上市公司财务健康度评估系统

> 基于多维度财务指标的A股上市公司信用风险量化评分模型

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 📌 项目简介

本项目是一个**独立的上市公司财务健康度评估系统**，覆盖沪深300成分股，通过量化分析四大核心财务指标（ROE、资产负债率、流动比率、营收增速），构建多维度风险评分模型，输出可视化评估报告。

**核心能力：**
- 🔄 自动从 akshare 拉取A股财务数据
- 📊 多维度财务指标评分与加权综合得分计算
- ⚠️ 智能识别"高负债+低现金流"高风险公司
- 📈 7张专业可视化图表 + 完整HTML报告
- 🏭 按行业分组对比分析

## 🚀 快速开始

### 环境要求
- Python 3.9+
- akshare、pandas、matplotlib、seaborn

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行项目

```bash

python main.py

python main.py --auto
```

运行完成后，打开 `reports/financial_health_report.html` 查看完整报告。

## 📊 评分模型说明

### 四大核心指标及权重

| 指标 | 权重 | 说明 | 评分方向 |
|------|------|------|----------|
| **ROE（净资产收益率）** | 30% | 衡量股东回报能力 | 越高越好 |
| **资产负债率** | 25% | 衡量长期偿债压力 | 适中为佳（40%-60%） |
| **流动比率** | 25% | 衡量短期流动性 | 越高越好 |
| **营收增速** | 20% | 衡量成长性 | 越高越好 |

### 风险等级划分

| 等级 | 得分区间 | 含义 |
|------|----------|------|
| A-优秀 | ≥ 80 | 财务结构稳健 |
| B-良好 | 65 ~ 79 | 整体健康 |
| C-一般 | 50 ~ 64 | 存在改进空间 |
| D-关注 | 35 ~ 49 | 需关注风险 |
| E-高风险 | < 35 | 财务压力大 |

## 📈 可视化输出

本项目生成7张专业分析图表：

1. **综合得分分布直方图** — 整体得分分布与平均水平
2. **风险等级饼图** — 五级风险占比
3. **行业排名柱状图** — 按行业平均得分排序
4. **ROE-负债率四象限图** — 盈利能力vs偿债能力矩阵
5. **高风险散点图** — 高负债+低流动性识别
6. **维度箱线图** — 各维度得分离散度分析
7. **Top/Bottom对比图** — 健康公司与风险公司对比

## 📝 核心发现示例（基于当前数据）

- **整体评估**：100家沪深300成分股平均综合得分 **56.0分**，处于"一般"水平
- **行业差异**：白酒、能源金属、生物制品等行业财务健康度领先；银行、证券因高杠杆特征得分偏低
- **风险识别**：共识别出 **31家** "关注/高风险"公司，主要集中在金融和房地产板块
- **优质标的**：泸州老窖、贵州茅台、天齐锂业等位列健康度Top榜
